### 🤖 02 — TubeBrief AI
**AI-Powered YouTube Video Summarizer**

A web application that transforms lengthy YouTube transcripts into concise, structured summaries, helping users extract important ideas without reading or reviewing the entire transcript.

[![Live Demo](https://img.shields.io/badge/Live_Demo-10B981?style=for-the-badge&logo=streamlit&logoColor=white)](https://tubebrief-ai.streamlit.app/)
[![Source Code](https://img.shields.io/badge/Source_Code-181717?style=for-the-badge&logo=github&logoColor=white)](https://github.com/zaima-sohail/AI-Powered-YouTube-Video-Summarizer)

**Key features**
- 🎥 Extract transcripts from YouTube videos.
- ✍️ Summarize pasted transcripts when automatic extraction is unavailable.
- 🧠 Generate AI-powered summaries using Groq.
- 📌 Present important points, main topics, and key takeaways.
- 🌍 Produce English summaries from supported non-English transcripts.
- 📊 Display transcript and summary statistics.
- 📥 Download generated summaries.

**Technology stack**

`Python` · `Streamlit` · `Groq AI` · `YouTube Transcript API`

**What I explored:** AI integration, transcript processing, interactive UI development, environment-variable-based API key handling, and deployment of an AI-powered application.
