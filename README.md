### 🎥 1. TubeBrief AI — YouTube Video Summarizer

An AI-powered application that converts YouTube transcripts into concise, structured English summaries.

**Key features**
- Extract available video transcripts or paste transcripts manually
- Generate AI-powered summaries using Groq
- Identify important points, topics, and key takeaways
- Process supported non-English transcripts into English summaries
- View transcript statistics and summary visualizations
- Download generated summaries

**Technologies:** Python · Streamlit · Groq API · YouTube Transcript API
