### 🎥 TubeBrief AI — YouTube Video Summarizer

<a href="https://tubebrief-ai.streamlit.app/">
<img src="https://img.shields.io/badge/🚀_Try_Live_Demo-512DA8?style=for-the-badge" alt="Live demo"/>
</a>
<a href="https://github.com/zaima-sohail/AI-Powered-YouTube-Video-Summarizer">
<img src="https://img.shields.io/badge/View_Repository-181717?style=for-the-badge&logo=github" alt="Repository"/>
</a>

An AI-powered application that transforms YouTube transcripts into concise, structured summaries.

**Key features**
- 🎬 Extract available YouTube video transcripts
- 🧠 Generate summaries using Groq AI
- 📌 Identify key points and takeaways
- 🌍 Support summaries of available multilingual transcripts
- 📊 Present useful transcript and summary information
- 📥 Download generated results

**Built with:** Python · Streamlit · Groq AI · YouTube Transcript API
